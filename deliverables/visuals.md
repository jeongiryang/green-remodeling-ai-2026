# 예선 시각자료

2026-09-30 개정 4. 교정된 「2026산학과제OT설명자료.pdf」는 디자인·설명 구성의 참고이며 공모전 내용·제출 자료가 아니다. 밝은 회색 배경, 남색 제목과 청록 밑줄, Noto Sans KR, 넓은 여백을 적용했다.

[표지 일러스트](assets/GreenLoop_표지일러스트.png)는 제안서 1쪽, [서비스 흐름](assets/GreenLoop_서비스흐름.png)은 4쪽·요약서 1쪽, [서비스 화면 구성안](assets/GreenLoop_화면예시.png)은 3쪽·요약서 2쪽에 삽입했다. OpenAI 이미지 생성 도구로 만든 설명용 구성안이며 실제 시설·실측·사용자 응답을 보여주는 자료가 아니다.

흐름: 건물 선택 / 에너지 비교 / AI 불편 문진 / 개선 후보 비교 / 조사 요청서. 화면: 가상 공공도서관 A의 오후 창가 더위를 차양·창호·환기 점검 항목으로 연결한다. 절감률이나 달성한 성능 수치는 없다.

7·8·11쪽은 편집 가능한 PowerPoint 표다. 6쪽 처리 구조는 텍스트·도형으로 구성했다. PowerPoint에서 실제 열어 PDF로 변환했으며 13쪽 PDF, 요약서 2쪽과 행정 서류 전 페이지를 개별로 렌더링해 확인했다. 시각 검토 근거는 private/build/greenloop/revision4/qa에 보관한다.

그림은 제안서·요약서에 포함했다. 별도 PNG·미리보기·레퍼런스 PDF는 제출 폴더와 ZIP에서 제외했다.
