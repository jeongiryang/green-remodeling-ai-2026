# 예선 시각자료

2026-09-30 개정. [서비스 흐름 이미지](assets/GreenLoop_서비스흐름.png)는 제안서 3쪽과 요약서 1쪽에, [서비스 화면 구성안](assets/GreenLoop_화면예시.png)은 제안서 7쪽과 요약서 2쪽에 삽입했다. OpenAI 이미지 생성 도구로 제작했고 실제 공공도서관의 사진·이용자 응답·모델 실행 결과가 아닌 서비스 설명용 구성안이다.

흐름도: 건물 선택 / 에너지 비교 / AI 불편 문진 / 개선 후보 비교 / 조사 요청서. 각 단계의 입력과 제공 결과를 짧게 표기했다.

화면 구성안: 가상 공공도서관 A의 오후 창가 더위 응답을 차양·일사, 창호·외피, 환기·냉방의 점검 항목으로 연결하는 화면이다. 소비량 그래프·절감률·달성한 성능 수치는 없다. 이미지 속 설명용 사진도 생성된 요소다.

제안서 5쪽의 처리 구조와 8쪽의 후보 비교표는 편집 가능한 텍스트·도형을 유지했다. PowerPoint에서 최종본을 열어 PDF로 변환하고 13쪽 전체를 실제 렌더링했다. 요약서 2쪽도 렌더링해 본문·그림·출처·표의 잘림을 확인했다.

이미지 생성 프롬프트 요지: 녹색 계열의 한국어 5단계 흐름도, 공공도서관 불편 응답과 3개 개선 후보의 웹 화면. 생성 원본 PNG를 워크스페이스에 보관했다.
