# 데이터 접근·근거 검토 기록

확인일: 2026-09-28. 이 기록은 **자료 접근과 후보 설계 조사**다. AI 모델 실행·정확도 평가·실제 리모델링 성과 검증은 하지 않았다. 다운로드 원문은 `cache/`에 보관하고 Git에서는 제외한다. 성공·실패 URL, 바이트 수, 해시는 [access-checks.json](access-checks.json)에 기록했다. 기록에 checked_on이 없는 초기 요청도 모두 이 날짜에 수행했다.

## I001: 창호 견적·제품 성능

- 한국에너지공단 창세트 목록과 제품 상세를 로그인 없이 HTTP 200으로 받았다. 목록에서 관찰한 상세 링크를 따라갔다.
- 확인한 예: `(주)한솔에이치더블유디 / HS 93mm CM`, 알루미늄 프레임, 열관류율 **1.175 W/(m²·K)**, 효율등급 **2**, 유리 구성 표기. 이 수치는 제품 하나의 조회 결과이며 성능 추천·현행 적합성 판정이 아니다.
- 상세 HTML은 UTF-8로 읽었다. 초기 목록 캐시의 디코딩이 깨져 보이는 문제가 있어 제품 수치는 올바르게 해독한 상세 원문을 근거로 삼았다.
- 상세의 완료일자·기밀성등급은 추출상 값이 비어 있었다. 항목 존재만으로 값을 채우지 않는다. 제품 표기는 현장에 설치할 구성·치수·생산 시점과 동일하다는 보장이 없다.
- 갱신: 신고 정보가 바뀔 수 있으므로 실제 이용 시 다시 조회하고 확인일을 저장한다. 공개 검색 화면은 확인했지만 대량 API·스크래핑 허가·일괄 재배포 조건은 확인하지 않았다. 최초 시연은 사람이 확인한 소수 필드와 공식 링크로 제한한다.
- 실견적은 0건이다. 제안된 6쌍 합성 견적은 **평가 계획**이며 아직 견적 파일을 만든 상태가 아니다. 실제 필요성·OCR 정확도가 검증됐다고 쓰지 않는다.
- SI-SO는 공식 소개에서 OCR·가격·누락 공종 비교를 확인했다. 로그인 후 기능·성능을 직접 검증하지 않았다.

## I002: 설비 설명서·인수인계

- Daikin VAM150FC/VAM250FC 설명서 12쪽을 실제 다운로드하고 텍스트를 읽었다. 문서 식별자 `4P586308-1`, 2019.06. PDF 3쪽=인쇄 1쪽부터 본문이다.
- PDF 3~7쪽에서 인계 안내, 연결 방식별 조작 차이, 자동/열회수/바이패스 모드, 전문 유지관리 범위를 확인했다. 본선 샘플은 이 모델의 버전을 고정하고 근거 쪽을 연결할 수 있다.
- 이 해외 모델이 국내 대상 시설에 설치돼 있다는 증거는 없다. 현장에 적용할 때는 실제 모델·제어기·설치 방식에 맞는 설명서가 필요하다.
- LG에서 받은 16쪽 PDF는 **가정용 욕실 일반 배기팬** 자료였다. 열회수 환기설비의 대체 자료로 쓰지 않는다. 잘못된 문서를 연결하면 멈추는 부정 입력으로 활용할 수 있다.
- 힘펠 설명서 2개와 카탈로그는 HTTP 400이었다. 검색 결과가 보였다는 이유로 원문 접근 성공으로 기록하지 않았다.
- 설명서 공개와 저작권 양도는 다르다. 원문 PDF·대량 발췌를 저장소나 제품에 재배포하지 않고 링크·검증한 최소 사실과 사용자 적법 보유 자료 중심으로 구성한다. 실제 외부 AI 업로드 전 문서 사용 조건도 확인한다.
- 실제 시설 인계 메모·한국어 안내 검수·사용자 평가 없음. AI가 유지관리 주기나 안전 조작을 임의 생성하지 않게 설계한다.

## I003: 거주자 의견

- CBE의 서비스 소개·측정 영역·FAQ 본문을 읽었다. 열쾌적·공기질 등의 **상위 분류와 기존 업무**를 이해하는 참고 자료다.
- 설문 응답 원자료는 확보하지 않았다. FAQ는 문항과 벤치마킹 지표의 복제를 허용하지 않는다고 명시한다. 기존 문항을 번역·복제하는 대신 자체 문항을 설계한다.
- 한국 노후 다세대 거주자 인터뷰·불편 기록은 0건이다. 후보 검증에 제안한 합성 사례 12개도 향후 제작 계획이다. 합성 사례에서 좋은 결과가 나와도 실제 수요나 상담 성과로 일반화하지 않는다.
- 사용자 입력 단위는 공간·시각/시간대·계절·상황·주관적 진술이다. 설비 성능 측정치와 구별하고 주소·건강정보는 필수로 받지 않는다.

## I004: 이해관계 조건

- IEA의 분리 유인 설명과 호주 정부 그린리스 소개 본문을 읽었다. 구조적인 문제와 기존 해결 방식의 근거다.
- 소개 문서가 한국의 계약 데이터·법률 검증 자료는 아니다. 실제 양측 비용 한도·공사 허용일·사용 계획은 당사자가 직접 입력하고 확인해야 한다.
- 호주 임차인 가이드 PDF는 시간 초과, 미국 DOE PDF는 인증서 검증 오류로 받지 못했다. 이를 근거 자료로 등록하지 않았다.
- 실제 계약·금융 거래·인터뷰 확보 없음. 가상 공사비 1,000만원 등의 숫자는 계산 동작을 설명하는 합성 예시이며 시세·현장 견적이 아니다.

## I005: 계량·기상 시계열

| 자료 | 실제 확인 범위 | 주요 필드·단위 | 한계 |
|---|---|---|---|
| BDG2 README | 원문 다운로드 | 2016~2017, 북미·유럽 1,636개 건물·3,053계량기 소개 | 국내 대표 표본 아님 |
| metadata.csv | 실제 1,636행, 272,024바이트 | building_id, site_id, primaryspaceusage, sqm, timezone, yearbuilt 등 | 연식·이용자 수 등의 결측 확인 |

| LICENSE | 실제 원문 다운로드 | 첫머리 `Attribution-ShareAlike 4.0 Unported` | 외부 소개의 단순 CC BY 표기와 동일하다고 처리하지 않음 |

`raw.githubusercontent.com`의 metadata 응답 131바이트는 CSV가 아니라 Git LFS 포인터였다. HTTP 200만으로 실데이터 확보로 처리하지 않고 `media.githubusercontent.com`에서 실파일을 다시 받아 행·열을 확인했다. 전력 자료는 대용량 전체 대신 스트리밍으로 처음 24시간만 읽었다. 데이터 저자의 논문과 저장소를 출처로 명시하고 원자료는 이번 커밋에 포함하지 않는다.

데이터는 고정된 2016~2017 관측 자료로 현재 건물 상태를 나타내지 않는다. 계량값 0이 휴관인지 센서 이상인지 자료만으로 확정하지 않는다. 공사 시점·시공 내용·운영 변화의 정답이 없으므로 두 해 사이의 차이를 **리모델링 절감 성과**로 해석할 수 없다. 실제 성과를 검증하려면 국내 대상 건물의 적절한 전후 계량·기상·공사·운영 기록이 별도로 필요하다.

OpenDSM 공식 README에서 일·월·시간 모델, 충분성 검사·경고 기능을 확인했다. 라이브러리는 설치하거나 실행하지 않았다. 후보에 도입한다면 라이선스·버전·입력 적합성부터 확인한다.

## 사실·가설·목표 구분과 반대 검토

- **사실:** 위 원문에 적힌 업무·서비스 기능 설명, 직접 접근한 자료의 구조와 범위.
- **가설:** 한국의 특정 이용자가 이 서비스를 원한다, 기존 방식보다 편하다, 실제 공사 의사결정·운영이 개선된다.
- **추정:** 후보별 인시. 기본 웹/Python 담당과 API 사용을 가정한 범위이며 학습시간·섭외·상용화 제외.
- **목표:** 각 후보의 90% 필드 보존·오류 0건 등. 실제 성능 측정 결과가 아니다.
- **미확인:** 팀 기술·시간·API 사용 환경, 실고객 데이터, 사용자·전문가 검증, 정확한 API 비용.

반대 검토는 같은 세션이 조사 결과를 다시 대조해 수행했다. 독립된 전문가 심사나 별도 에이전트 검토로 표시하지 않는다. 검사 도구의 통과는 필드·출처 연결이 갖춰졌다는 뜻이며 아이디어의 수요·효과를 인증하지 않는다.

AI 활용 기록: Codex를 이용해 공식·1차 자료 검색, 출처 요약, 후보 구성, 비교·반론 및 문서 작성을 수행했다. 최종 제출물에는 선택된 아이디어에 실제 사용한 범위를 별도로 명시해야 한다.

## 2026-09-29 추가 접근 — I006·I007

출처 IDEA-S19~24의 6건을 새로 등록했다. DOE 종합 개선 안내, PNNL 벽 단열·창호 체크리스트, CompanyCam 도움말 HTML과 EU 2020 전략 PDF를 로그인 없이 내려받았다. 상태·해시는 access-checks.json에 추가했다. PNNL RESNET 안내는 웹 본문 Ensuring Success에서 읽었으며 별도 파일 다운로드로 기록하지 않았다.

- **I006 데이터:** 상담 메모에서 추출할 작업·시기·확인 상태와, 근거가 있는 선행 조건의 설계에 사용한다. DOE의 누수/단열 관계 예를 확인했고 EU PDF 9쪽의 단계적 개선·로드맵 선행 개념을 읽었다. 실제 현장 상담·단가·국내 공법별 의존관계 자료는 없으며 합성 8개 사례도 향후 검증 계획이다. EU 자료는 2020 전략의 선행 아이디어 참고이며 현행 국내외 법적 요건으로 인용하지 않는다.
- **I007 데이터:** 공개 체크리스트를 읽고 작업·공간·단계·기록 유형 필드를 설계했다. 미국 골조벽·창호의 시공 수치·법규를 국내 건물에 자동 적용하지 않는다. 한국 현장 사진·작업 일지·검수 정답은 확보하지 않았다. 최초 시연은 합성 작업 설명과 샘플 첨부로 문서 연결을 검증하고, 사진 내용 판독·열성능 산출을 하지 않는다.
- **기존 서비스 확인:** CompanyCam 도움말에서 사진 요구·문서 변환·조건부 항목·AI 체크리스트 존재를 확인했다. 계정 실행·정확도 비교는 하지 않았다. 따라서 AI 체크리스트 최초성은 주장하지 않는다.
- **이용조건·갱신:** 공개 열람이 원문·이미지 재배포 허가를 뜻하지 않는다. 원문은 Git 제외 캐시에 두고 자체 요약·출처 링크·자체 합성 사례를 사용한다. 기술 규칙은 출처 버전·적용 공법을 기록하고 국내 적용 전 검수한다. 서비스 도움말은 기능 변경 가능성이 있으므로 실제 구현 때 재확인한다.
- **평가 한계:** 두 후보의 90% 추출 목표·오확정 0건은 아직 실행하지 않은 목표다. 합성 사례 계획·작업량 추정과 실측 성능을 구분한다. 기존 5개와 동일하게 API·팀 담당·시간이 미확인이라 conditional로 유지한다.
