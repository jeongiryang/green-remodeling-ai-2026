# I008 GreenLoop — 에너지·이용자 불편 통합 사전점검

2026-09-30. 그린스캔(I008)의 확보 데이터·품질/비교 코어를 유지하고 구조화 불편 문진·요청서 저장으로 확대했다. 사용자가 최종 제출자료 제작과 팀명 선정을 위임했고, 팀명은 **그린루프**, 작품명은 **GreenLoop**로 적용했다. 상세 범위는 [candidates.json](../candidates.json)의 I008과 [최종 비교](GreenLoop_최종추천.md), [결정](../decision.md)에 기록했다.

공공시설 담당자가 건물 선택 → 자료 품질·유사 조건 비교 → 불편 문진/응답 확인 → 개선 후보별 필요한 증거 → 현장조사 요청서를 진행한다. 전체 에너지, 이용자 진술, 원인 가설은 동일 건물 ID로 연결하되 같은 원인이라고 추론하지 않는다. 첫 대상은 공개 목록에 포함된 노후 공공건축물 한 동이고 도서관 응답 화면은 가상 사례다.

## 구현 준비 판단

핵심 범위 `ready`: 확보된 정적 CSV, pandas·NumPy 회귀/집계 기준선, 구조화 문진, 규칙 검사와 요청서 저장. 현재 환경에서 pandas·NumPy 존재를 확인했다. sklearn은 없어 필수에서 제외했다. API·LLM 키·현장 센서·도면이 핵심 시연에 필요하지 않다. 기본 웹/Python 작업을 전제한 내부 준비 판단이며 팀 숙련도·시간·담당 확정과 구현 완료를 뜻하지 않는다.

LLM 자유문 구조화·추가 질문·요약 확대는 `conditional`: API 키/비용 또는 로컬 모델 실행 장비가 미확인이다. 이 조건은 해소된 것으로 기록하지 않는다. 고정 폼 대체를 LLM 실행이라고 표시하지 않는다. 확대안 44~68인시, 핵심 약34~52인시는 내부 추정이고 학습시간 별도다. 제품 구현은 본선 진출 확인 후다.

## 데이터·AI·검증

공개 CSV 4,347행·15열을 직접 확보했다. SHA-256 `1a049b33df564410508ebbf1164d401d660eae75fcaa8f2de3c27367ac9c883a`. 미보고 분기0·양의 원단위·유효면적/연도 기본조건 3,681행. 연면적3,000㎡ 이상 공공건축물 중심, 3개년 평균 1차 에너지 원단위(kWh/㎡·년)이며 월별·공간별·CO₂·도면·자재·창호 사양 자료가 아니다. 원본은 `private/research/public-building-energy.csv`에 있다.

회귀는 지역·용도·면적·연도·층수를 입력한다. 주소/기관은 그룹 분리에만 쓰고 이름·주소·공개 중간값은 학습 특성에서 제외한다. 같은 미사용 그룹에서 중앙값과 MAE·구간 커버리지를 비교한다. 품질/비교군 부족은 보류하고 모델이 기준선보다 나쁘면 AI 우월을 주장하지 않는다. LLM은 동의받은 자유문을 구조화하고 원문 인용/사용자 확인을 거쳐 필요한 질문·요약만 제안한다. 수치 계산·절감률·공사 원인 판정은 맡기지 않는다.

Greeny는 이미 시나리오 에너지/CO₂/공사비를, CBE는 분기 설문과 건물 비교를 제공한다. 문진의 최초성이나 ChatGPT가 할 수 없다는 주장은 하지 않는다. 차별 가설은 출처·단위·기간·누락·모순·보류·사용자 확인을 반복 가능한 요청서로 연결하는 업무 가치다. 고정 설문·일반 LLM·집계 기준선과 검증한다. 모델·LLM·사용자 효용·현장 원인·절감 효과는 아직 측정하지 않았다.
