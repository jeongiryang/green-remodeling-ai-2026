# GreenLoop 최종 추천과 후보 검토

2026-09-30 한국 시간. 기존 7개 후보, 선정된 그린스캔, 팀원 GreenLoop 보강안과 신규 10개 방향을 함께 검토했다. **최종 추천은 GreenLoop — 노후 공공건축물의 에너지와 이용자 불편을 연결하는 AI 현장조사 준비 서비스**다. 추천 결과이며 사용자 확정·제출 완료가 아니다. 현재 선정 ID I008과 기존 초안은 유지한다. LLM까지 포함한 확대안의 준비 상태는 조건부다.

## 추천 이유와 반론

공모 주제의 노후 건축물과 이용자 특성을 함께 다루며, 시설 담당자가 다음 현장조사에 필요한 정보를 모으는 행동까지 연결한다. 현재 확보한 공공 에너지 CSV를 활용하고 센서·도면 자동 조회·공사 전후 계산을 필수로 하지 않는 경로를 설계할 수 있다. 단독 문진보다 데이터 근거를 연결하고, 에너지 비교만 하는 그린스캔보다 이용자 불편과 조사 목적을 구체화한다는 내부 판단이다.

실제 수요·효과는 입증되지 않았다. CBE도 이미 분기 설문, 실내환경 불편 보고와 유사 건물 비교를 제공한다(IDEA-S29). ‘최초 AI 문진’ 또는 ‘ChatGPT가 못 하는 분석’은 주장하지 않는다. 자료의 비교 가능성, 응답 근거, 시간·공간 범위와 미확인 사항을 관리하고 조사 요청서로 인계하는 흐름의 추가 가치를 검증해야 한다.

## 최종 추천 범위

사용자는 공공시설 담당자다. 첫 시연은 공개 목록에서 용도·노후도·비교 표본을 확인한 건물 한 동으로 좁힌다. 도서관 창가 불편은 이해하기 쉬운 설명 사례로 우선 검토하지만 실제 건물 선정·현장 자료 확보는 아직 없다. 소형 민간 업무시설은 실제 월별 자료와 계량 범위 확인 후 추가한다.

1. 건물 선택과 품질 확인: 지역·용도·면적·사용승인연도·소비 원단위·보고 누락을 읽는다.
2. 에너지 사전점검: 유사 조건의 참고 범위와 비교한다. 회귀 모델이 집계 기준선보다 나쁘거나 표본이 부족하면 AI 신호를 보류한다.
3. 불편 문진: 위치·시기·증상·빈도·이용시간·기존 대응을 받는다. 실제 응답과 설명용 샘플을 구분한다.
4. 추가 확인: LLM이 자유 서술을 구조화하고 빠진 정보·모순의 확인 질문을 제안한다. 사용자가 수정·확인하며 원문을 남긴다.
5. 개선 후보별 확인사항: 창호·차양·설비 등의 적용을 검토할 이유와 필요한 현장 자료를 제시한다.
6. 조사 요청서 저장: 관측 에너지, 이용자 응답, 원인 가설, 추가 확인사항과 출처를 구분한다.

‘여름 오후 서쪽 창가가 덥다’는 불편 진술이다. 차양·창호·냉방 운영을 확인할 이유가 될 수 있지만, 높은 건물 전체 사용량과 같은 원인이라고 결론내릴 수 없다. 온도·CO₂·공간별 소비량·누수 여부를 없는 자료에서 만들어내지 않는다.

## AI와 검증

에너지 수치는 Python에서 계산·평가한다. LLM에는 확인된 수치와 응답을 전달해 위치·시기·증상·누락 정보를 추출하도록 한다. 결합 학습용 정답 자료가 없어 ‘에너지와 불편을 학습해 원인을 진단하는 모델’은 현재 주장할 수 없다. 고정 설문·규칙으로 충분한 기능에 LLM 우월을 주장하지 않는다.

LLM 모델·API 키·비용 또는 로컬 실행 장비는 미확정이다. 새 LLM의 처음부터 학습은 최소 구현에 넣지 않는다. 키가 없으면 구조화 입력과 고정 분기 질문으로 기본 흐름을 시연할 수 있지만, 이를 LLM 동작이라고 표시하지 않는다. **LLM 확대안은 conditional이며 기존 ready인 I008로 자동 교체하지 않는다.**

본선에는 같은 자료를 받은 범용 LLM, 고정 설문+수동 요청서, 집계 중앙값을 대조한다. 추출 정확성, 관련 없는 질문, 확인사항 누락, 모순 처리, 근거 연결과 임의 수치 생성 여부를 사람 기준과 비교한다. 에너지 모델은 주소/기관 그룹을 분리해 오차·구간 커버리지를 평가한다. 현장 요청서 활용성과 실제 원인·공사 효과는 별도 검증으로 남긴다. 비교 시험은 아직 미실시다.

## 데이터와 난이도

현재 CSV는 3개년 평균(IDEA-S25)이어서 월별·야간·공간별 분석을 할 수 없다. 건축HUB 월별 지번 자료(IDEA-S27)는 실제 응답·건축물 결합·계량 범위 검증 후 확장한다. 한 필지에 한 동이어도 그 확인을 생략하지 않는다.

개선 후보는 조사할 선택지 수준이다. 정량 GreenTwin·절감률·공사 후 사용량·차양 위치 최적화는 자료와 계산 검증을 확보한 후의 범위다. 국내 지침·건물 자료를 보강해야 하며 DOE/PNNL 창호 목록(IDEA-S24)은 확인항목 형식의 참고이지 국내 시공 규격이 아니다.

기본 웹·데이터·구조화 문진 시연은 중간 난이도라는 내부 판단이다. LLM 추출·추가 질문·검증까지 포함하면 중간 이상이며 기존 28~44인시를 그대로 적용할 수 없다. 모델 실행 방식·담당·평가 사례를 정한 뒤 산정한다. 준비 조건은 LLM 실행 경로, 검수한 질문·개선 후보 근거, 동일 건물 연결, 팀 담당·시간이다.

LLM 실행 경로가 없거나 고정 설문·동일 자료의 범용 LLM 대비 가치가 없거나 담당자가 요청서를 활용하지 않으면 추천을 재검토한다. 기존 그린스캔 축소안 또는 실견적이 확보된 그린견적이 대안이다.
