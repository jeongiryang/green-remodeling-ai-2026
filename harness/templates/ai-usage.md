# AI·외부 자료 활용 기록 틀

실제 기록: `deliverables/ai-usage.md`. 사용하면서 기록하고 도구·모델명을 추측하지 않는다.

| 날짜 | 도구·모델/자료 | 활용 범위·입력 유형 | 적용 산출물·부분 | 출처·라이선스 | 사람이 확인·수정한 내용 |
|---|---|---|---|---|---|

기획·조사 정리·집필·코드·이미지·도표 등 실제 활용한 범위를 각각 명시한다. 비공개 개인정보나 API 키·원문 전체 프롬프트를 이 기록에 붙이지 않는다. 외부 이미지·폰트·데이터·오픈소스의 출처와 이용 조건도 함께 관리한다.
