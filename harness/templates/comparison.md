# 후보 비교 작성 틀

실제 작업 시 `research/comparison.md`에 작성한다. 아래 지시문 자체를 산출물로 복사해 완료 처리하지 않는다.

1. 탐색 범위: 건물 유형 × 이용자 × 그린리모델링 단계(진단·선택·시공 의사결정·운영·사후 검증).
2. 실제 문제: 관찰·공식 자료·연구의 출처 ID, 발생 상황, 현재 해결 방식과 불편.
3. 후보 3~5개: 문제와 AI 역할이 서로 구별되는 후보. 기술 이름만 다른 후보는 합친다.
4. 데이터 검증: 실제 열어본 원본·컬럼·기간·단위·접근 조건. 미확보 데이터는 명시하고 대체 경로 검토.
5. 기존 방식·서비스 비교: 각 서비스 공식 출처, 실제 기능, 우리 접근과의 구체적 차이.
6. 내부 평가: 문제20·적합성20·창의성25·실현가능성20·본선 발전15의 가중치. 점수마다 이유와 불확실성.
7. 추천 후보 1~2개와 보류 사유. 추천이 바뀔 조건과 남은 확인 사항.

사람에게 보여줄 비교표에는 후보명 / 대상·문제 / AI가 하는 일 / 데이터 확보 상태 / 차별성 / 예선 표현 가능성 / 본선 최소 구현 / 주요 위험을 담는다.
