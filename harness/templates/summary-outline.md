# 공식 제안요약서 집필 틀

실제 집필: `deliverables/summary.md`. 최종본은 별첨4의 구조를 유지해 HWP 또는 PDF로 작성하고 A4 2쪽 이내인지 실제로 확인한다.

- 팀명·작품명. 참가번호는 운영기관 작성 칸.
- 제안배경 및 문제점: 건물·이용자·현재 불편·근거.
- 아이디어 개요: 누구에게 무엇을 제공하고 무엇을 바꾸는가.
- 핵심 기능 및 이용 흐름: 입력부터 사용자 행동까지.
- 그린리모델링 연계방안: 건축·설비·운영 개선과 서비스 연결.
- 실현·확장 가능성 및 기대효과: 데이터·구현·운영 계획, 과장 없는 효과.
- AI 적용 기능 표: 적용 기능 / 활용정보·데이터 / AI 활용 내용 / 제공 결과.
- AI를 쓰는 이유와 기존 방식 대비 장점.

제안서와 기능·수치·용어가 달라지지 않게 확인한다. 학교·성명은 심사용 요약서에 넣지 않는다.
