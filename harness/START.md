# 다음 실행 요청

아래 요청으로 현재 단계의 실제 작업을 시작할 수 있다.

> AI 플랫폼 아이디어 부문의 후보 탐색을 시작해. 먼저 하네스 status와 next, `harness/IDEATION.md`를 확인해. 공고의 예선 평가기준에 따라 노후 건물·이용자의 문제, 실제 열어본 데이터, 기존 서비스와 비AI 대안을 조사해. 문제와 해결 방식이 다른 후보 3~5개를 `research/sources.json`과 `research/candidates.json`에 기록하고 `research/comparison.md`에서 비교해. 각 후보의 근거 출처를 문제·그린리모델링 연결·데이터·기존 방식별로 연결하고, AI 입력·처리·출력·필요성·검증, 예선 화면, 본선 최소 구현과 위험을 따로 설명해. 치명적인 데이터/AI/검증 결함이 있는 후보는 점수와 별개로 보류해. 1~2개를 추천하고 추천이 바뀔 조건을 제시한 다음 사용자가 주제를 정할 수 있게 해줘.

이 파일은 재사용할 시작 문구다. 작성했다고 실제 조사가 실행되거나 후보가 확정되는 것은 아니다.
