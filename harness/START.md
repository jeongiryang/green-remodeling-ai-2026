# 다음 실행 요청

아래 요청으로 현재 단계의 실제 작업을 시작할 수 있다.

> AI 플랫폼 아이디어 부문의 후보 탐색을 시작해. 먼저 하네스 status와 next를 확인하고, 공고의 예선 평가기준을 기준으로 노후 건물·이용자 문제, 실제 사용 가능한 데이터, 기존 서비스의 한계를 조사해. 서로 다른 후보 3~5개를 sources.json과 candidates.json에 기록하고 comparison.md에서 비교해. 각 후보에 AI 필요성, 그린리모델링 연결, 예선에서 보여줄 화면, 본선에서 구현 가능한 최소 범위와 위험을 설명해. 추천 이유와 불확실성을 제시한 다음 주제를 정할 수 있게 해줘.

이 파일은 재사용할 시작 문구다. 작성했다고 실제 조사가 실행되거나 후보가 확정되는 것은 아니다.
