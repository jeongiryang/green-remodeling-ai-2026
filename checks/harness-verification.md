테스트용 후보·서류·PDF/PPTX는 임시 폴더에서 만든 가상 데이터다. 실제 후보·증명서·서명·접수 증빙이 아니다. 테스트는 파일 구조와 기록 처리만 검증한다.

실제 문서의 사실성·창의성·서명·시각 품질·PDF/HWP 쪽수는 사람이 파일을 열어 확인한 기록에 의존한다. 실제 웹 제출이나 본선 앱 구현은 이번 구축 검증 범위에 포함되지 않는다.
