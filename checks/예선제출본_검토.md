# GreenLoop 예선 제출본 검토 — 개정 2

2026-09-30 / Codex 개정 제출본 검토 세션. 사용자 요청: 글꼴 서명을 흘림 손글씨 이미지로 교체, 요약서 본문·시각자료 확대, 내부 점검 문구 정리, 핵심 기술 책임 분담. 실제 신청·전송·접수는 수행하지 않았다.

## 공식 규격 및 원본

같은 날 공식 공고·AI 서식 재확보와 원본 해시 대조를 수행한 앞선 검토를 기준으로, 15쪽 이내 PPT/PDF와 A4 2쪽 공식 요약서, 행정 서식·전원 증빙 조건을 적용했다. 원본 파일은 변경하지 않았다. 미성년자 없음은 기존 전원 증명서 대조 기록 기준이다.

## 문제·기존 방식·AI·주장

서비스는 노후 공공시설 담당자의 조사 준비를 지원하는 아이디어다. 건물별 에너지 비교, 불편의 장소·시간·증상 구조화, 개선 후보별 점검 항목, 조사 요청서 저장을 설명한다. 범용 LLM의 불가능·최초성·측정한 우월성을 주장하지 않고, 데이터 연결·응답 확인·근거 추적·표준 조사 항목의 업무 흐름을 차별점으로 설명한다.

확보 데이터는 국토안전관리원 「공공건축물 에너지 소비량_20260331」 공개 CSV, 4,347행·15열이다. 자료명·제공기관·공공데이터포털 원문 URL을 제안서 4·13쪽과 요약서 2쪽에 표시했다. 건물 특성과 3개년 평균 원단위를 활용하며 월별·공간별 관측값을 만든 주장은 없다. 기본 전처리 3,681행·44~68인시·API 제외 등 내부 수치는 개정 제출본에서 제외했고 claims.used_in을 갱신했다.

회귀 비교와 LLM 문진·요약은 서비스 기능 설계로 설명한다. 품질 관리에는 자료 단위·보고 누락, 원문 연결·응답 확인, 필수 항목 검사, 건물 그룹 분리·모델과 집계 비교를 포함한다. 기대효과를 달성한 성능이나 실측 절감률로 쓰지 않았다. 공개 자료 확보 외 제품 모델 학습·LLM 호출·사용자 및 현장 성능 평가는 수행하지 않았으며, 최소 코어와 실행 환경이 필요한 LLM 확대의 구분은 내부 research 기록에 남긴다. 제출 문안에서 ‘미측정·미실시·본선에서 검증·향후 확인’ 표현을 제거했음을 텍스트와 PPTX XML로 검사했다.

## 실제 파일·시각 검토

- PPTX 13쪽: @oai/artifact-tool로 기존 디자인을 반영해 개정했다. 구조·크기·폰트·텍스트 범위·재임포트 검사 통과. PowerPoint에서 실제 열어 13쪽 PDF로 변환했다. private/build/greenloop/revision2/deck/validation.json.
- 제안서 PDF 13쪽: 전체 페이지 PNG를 개별로 열어 본문·표·그림·출처·여백을 확인했다. 최종 PDF와 PowerPoint 내보낸 PDF의 각 페이지 내용 스트림이 같고 메타데이터만 정리했다.
- 요약서 PDF A4 2쪽: 공식 로고·제목·팀명·참가번호·작품명·5개 본문 항목·AI 4열 표를 유지했다. 원본 PDF에 포함된 로고를 추출해 헤더에 배치하고 항목·행 높이를 재구성했다. 본문·서비스 흐름 이미지·화면 구성안·출처·AI 도구 고지가 모두 들어 있다. 글자와 이미지의 잘림·표 겹침·페이지 번호를 최종 렌더로 확인했다.
- 신청·동의 PDF 2쪽: 정보·동의 표시·날짜를 유지했고 3인 주요 역할 셀을 기술 책임으로 개정했다. 네 명의 손글씨 이름 표식을 각 서명 칸에 넣었다. 전 페이지 실제 렌더 확인.
- 서약 PDF 1쪽: 9개 조항·주석·신청 안내 문장·날짜·동의·서명을 확인했다. 안내 문장 3줄을 원문대로 복원하고 서명 이미지가 행 경계와 겹치지 않게 조정했다. 최종 렌더에서 3개 안내 문장과 9개 조항·주석·표·서명 모두 읽힌다.
- 자격 증빙 4건: 각각 1쪽이고 이전 실제 화면 대조를 수행한 원본 파일과 SHA-256이 동일하다. 증명서 바이너리를 변경하지 않았다. 발급기관 온라인 진위조회는 별도로 수행하지 않았다.

최종 화면 근거는 private/qa/greenloop/revision2에 보관하고 제안서 13쪽 렌더는 private/build/greenloop/revision2/slide-01~13.png에 있다. 심사자료 PDF 텍스트/메타데이터와 PPTX XML에서 성명·학교·연락처·이메일이 없음을 검사했다. 서비스 그림 2개가 PPTX에 삽입되어 있고 흐름도는 3쪽, 화면은 7쪽이다. 예시 화면에 실측 수치·절감률·실제 이용자 결과가 없다.

## 서명·기술 책임 검토 범위

사용자가 전원 승인 및 손글씨 형태의 이름 적용을 요청했다. 서로 다른 획·기울기의 새로운 손글씨 이름 PNG 4개를 제작했다. 원본 PNG는 변경하지 않고 같은 사람의 표식을 동의서·서약서에 일관되게 배치했다. 실제 필적 복제·인증형 전자서명으로 주장하지 않는다. 기존 글꼴 서명 텍스트는 PDF 내용 스트림에서 제거했다. 주최 수용 여부의 직접 확인은 없으며 이 검토는 효력 보증이 아니다. 민감한 이미지·프롬프트·행정 서류는 private에만 보관한다.

사용자 핵심 기술 분담 지시에 따라 정이량 AI 처리·LLM 문진, 신진하 웹·문진 데이터 구조화, 최길웅 에너지 AI·ETL, 황왕석 백엔드·요청서·통합 검증으로 책임을 배정했다. 실제 수행 이력·숙련도 인증으로 쓰지 않는다. 신청서의 좁은 역할 셀은 같은 책임의 짧은 표현을 사용했다.

## 묶음과 검사

manifest의 9개 파일과 ZIP 내부 9개 파일의 해시를 각각 대조했고 ZIP CRC 검사 통과. 제안서 PPTX/PDF·요약서와 행정서류·4인 증빙을 분리했다. PDF 암호·AcroForm 필드는 없고 모든 파일을 읽을 수 있다. ZIP은 로컬 준비 묶음이며 공식 전달 경로의 접수·수신을 검증한 것은 아니다. 27개 하네스 테스트와 구조 검사가 통과했다. 이번 파일·검토 근거에 대해 새 seal-review를 실행한다.
